# Clipboard History — Spec

A clipboard manager that lives in the menu bar, matches the Windows Win+V feature set, and feels native to macOS.
Deployment target: macOS 14. Developed on macOS 27.2.1 with Xcode 27.2 and Swift 6.4.

## 2. Keyboard (in the panel)
↑/↓ move · Return pastes · ⇧Return pastes as plain text (swapped by the "plain by default" setting) · ⌘1–9 quick-paste · ⌘P pin · ⌫ delete · ⌘⌫ clear unpinned · Tab / ⇧Tab switch tabs · Esc clears search, then closes · typing goes to search · right-click for a row menu.
⌫ deletes the selected item **only when the search field is empty**; otherwise it edits the search.

## 3. Default global shortcut: ⌥⌘V
- ⌘⇧V is "Paste and Match Style" in many apps, and ⌃⌘V / ⌥⇧⌘V are paste variants in some apps. ⌥⌘V is only bound in Finder (move a copied file, a context-specific action), which is the smallest conflict among V combinations and keeps the "V means paste" link with Win+V.
- Win+V cannot be mapped literally: ⌘V is paste and ⌃V is Emacs page-down in text fields.
- Risk: Finder's "Move Item Here" stops working while Clipboard History runs. This is documented, and the user can rebind.

## 4. Performance budgets
| Budget | Target | How it's measured |
|---|---|---|
| Hotkey → panel visible | < 100 ms p95 | signpost from the hotkey callback to `didBecomeKey`/first draw, 50 runs |
| Idle CPU | < 1 % | `ps -o %cpu` sampled over 10 min |
| RAM with 1,000 items incl. images | < 100 MB | `footprint`/`vmmap --summary` |
| 10 MB text / 50 MP image | no hang > 250 ms on main | main-thread hang detection with a signpost and a watchdog test |

## 5. Data model
`ClipItem { id: UUID, createdAt, lastUsedAt, kind: text|rtf|html|image|files|url|color, preview: String (≤ 2 KB), searchText (≤ 64 KB, lowercased and folded), sourceBundleID?, pinned, byteSize, contentHash (SHA-256 of the main representation) }`.
Each representation is stored as a blob file at `~/Library/Application Support/Clipboard History/blobs/<id>/<uti>` with mode 0600, and the directory is 0700.
Dedupe: if the new hash matches an existing item, that item moves to the top instead of a duplicate being added.

## 6. Out of scope
GIF search, cloud services other than iCloud, AI features, snippets/templates (not in Win+V).
